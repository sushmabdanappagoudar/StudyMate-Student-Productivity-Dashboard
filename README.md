# StudyMate – Student Productivity Dashboard

StudyMate is a responsive, browser-based productivity dashboard designed to help students organize study tasks, manage focus sessions, and save quick notes.

## Features
- Add, complete, and delete study tasks
- Set task priority (High, Normal, Low)
- 25-minute focus timer with pause, resume, and reset
- Focus-session counter
- Quick notes saved in the browser
- Rotating study tips
- Responsive layout for desktop and mobile

## Technologies Used
- HTML5 – page structure
- CSS3 – styling and responsive layout
- JavaScript – interactive functionality
- Browser Local Storage – saves tasks, notes, and session count on the device

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it with Live Server in VS Code.
4. No backend or API key is required.

## Note
This is a front-end productivity application. It does not connect to an AI model or send personal notes to a server. Data is stored locally in the browser.

## Project Purpose
The project demonstrates how a practical student-focused application can be planned and built using core web development skills.
